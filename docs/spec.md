# Partomate 仕様書

Partomateは、AIとのチャット対話を通じて部品在庫の登録・消費を行い、商品の構成管理、原価計算、棚卸時の資産評価を支援する在庫管理アプリケーションです。

## 画面構成

### トップページ（チャット）
- 初期表示では、中央のチャット入力欄と左上のナビゲーションのみを表示します。
- 対話開始後は、入力欄を下部へ移動し、メッセージアプリ風に履歴を表示します。
- AIはユーザー発話を解析し、在庫変更や商品組み立てのプレビューを返します。
- ユーザーが承認した変更だけをデータベースに反映します。
- 頻出部品名や定型文を素早く入力できるショートカットを用意します。

### 在庫数ページ
- 部品一覧をカテゴリで絞り込めます。
- 数量は手入力および増減ボタンで調整できます。
- 部品ごとに単価、通貨、購入日、低在庫しきい値を保持します。
- 棚卸評価では外貨建て価格を円換算して資産額を表示します。

### 商品ページ
- 商品名、説明、構成部品、構成数量を登録・編集できます。
- 構成部品の単価と通貨から、商品1個あたりの現在原価を計算します。
- 商品の組み立て操作では、構成部品の在庫をまとめて消費します。

### 設定ページ
- LLMプロバイダ（OpenAI互換 / Ollama）、API URL、モデル名を設定します。
- モデル一覧の取得に対応します。
- システムプロンプト、言語、テーマ、背景、送信キーを設定します。
- 管理者はユーザー追加・削除を行えます。
- Tailscaleなどからのアクセス制限用に許可ホストを設定できます。

## バックエンド・データベース

- バックエンドはFastAPI、データベースはSQLiteを使用します。
- 数量は長さや液量にも対応するため `REAL` として扱います。
- 部品カテゴリは最大3階層（category1 / category2 / category3）です。
- 認証はID・パスワード方式で、パスワードはハッシュ化して保存します。
- 初回起動時は管理者セットアップを表示します。
- 権限は `admin` と `user` の2種類です。
- SQLiteはWALモードで動作します。

## MCPサーバー

外部LLMクライアントから在庫と商品構成を参照・操作するため、MCPサーバー機能を備えます。

予定ツール:
- `get_parts_list`: 在庫部品の一覧を取得
- `update_part_quantity`: 部品在庫の数量を変更
- `get_products`: 商品一覧と構成部品を取得
- `create_product`: 新しい商品を登録
